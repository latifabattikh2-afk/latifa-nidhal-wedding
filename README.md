# Latifa & Nidhal — Wedding invitation starter

This is a starter package, not a published or production-ready website.

## Files
- `index.html`, `styles.css`, `app.js`: initial invitation page scaffold.
- `config.js`: add your Supabase Project URL and Publishable key here.
- `schema.sql`: initial database setup reference.

## Important
Do not put a Supabase `service_role` or secret key in browser code.
Before publishing, the RSVP update flow, admin dashboard, upload controls,
moderation, and database/storage security policies must be completed and tested.
The venue, final music file, and final public website URL are still required.
